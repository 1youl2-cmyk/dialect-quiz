1. 압축을 풉니다.
2. 기존 dialect-quiz 저장소에서 Add file → Upload files를 누릅니다.
3. 폴더 안의 파일 5개(index.html, style.css, app.js, data.js, README.md)를 저장소의 기존 파일과 같은 위치에 올립니다.
4. Commit changes를 누릅니다.
5. Pages 게시가 완료되면 기존 주소에서 확인합니다. 예전 화면이 보이면 Ctrl+Shift+R로 새로고침합니다.

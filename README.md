# 말 모음 · 지역 방언 카드

제공된 `방언(2).hwpx`의 단어와 뜻을 그대로 옮긴 학습 프로그램입니다.
경상도 18개, 전라도 13개, 강원도 16개, 제주어 21개, 북한 생활 어휘 16개로 총 84개입니다. 어휘의 정확성을 별도로 교정하지 않았습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 설치, 서버, 회원가입이 필요 없습니다.
지역을 선택하면 무작위 순서로 카드가 나옵니다. ‘뜻 확인하기’를 누르면 뜻이 표시되고, ‘다음 방언’으로 이동하면 뜻이 다시 숨겨집니다. 한 바퀴 동안 중복 없이 모든 표현을 보여 주며, 마지막 카드에서는 다시 섞어 학습할 수 있습니다.

## GitHub에 올리기

1. 압축을 풀고 GitHub에서 새 저장소를 만듭니다.
2. 저장소의 **Add file → Upload files**에서 `dialect-cards` 폴더 **안의 파일들**을 업로드합니다. `index.html`이 저장소의 가장 위에 있도록 올립니다.
3. 웹사이트로 사용하려면 저장소 **Settings → Pages**에서 **Deploy from a branch**를 선택하고 `main`, `/ (root)`를 지정하여 저장합니다.
4. 게시가 완료되면 Pages 화면에 표시되는 주소로 접속합니다.

## 단어 수정

`data.js`의 `name`은 지역명, `word`는 방언, `meaning`은 뜻입니다. 같은 형식으로 표현을 추가하거나 수정할 수 있습니다.

## 파일

- `index.html`: 화면
- `style.css`: 디자인 및 모바일 화면
- `data.js`: 원본에서 추출한 어휘
- `app.js`: 카드 전환, 뜻 공개, 무작위 순서

외부 서비스나 라이브러리를 사용하지 않습니다.
